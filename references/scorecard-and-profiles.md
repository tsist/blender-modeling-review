# 五梯度计分规则、用途配置与 JSON 格式

每次审核先选定**用途配置档**和**目标等级**，再按统一分值逐项打分。

## 一、按交付用途选检查侧重点

| 用途配置 | 典型委托 | 重点加严项 | 合理放宽项 |
|---|---|---|---|
| **可编辑硬表面白模**（`stage=white`） | 资产审看①、产品造型定稿 | 控制笼稀疏可读、四边循环顺畅、卡线与细分高光平顺、一次局部试改通过、分件装配间隙闭合 | G5（UV/材质）标为不适用，总分按前四项 85 分满分折算成 100 分 |
| **原生资产库成品**（`L2/L3` 默认） | 入 `<ASSET_LIBRARY>` 供跨场景拖入复用 | 根集合资产标记、保留可编辑修改器栈与着色节点、另附干净工程纯贴图版、Cycles 与 EEVEE Next 光追一致 | 有护边的纯平面静态封口共面 N-gon 允许保留 |
| **游戏与实时电商导出**（`game` / `GLB`） | 进 Unreal / Unity / Web 3D 展示 | 面数与材质球预算、清零全部 N-gon、固化修改器与切分法线、纹素密度均匀、必要时附 `UVMap_Lightmap` 第二套 UV 与碰撞体 `COLL_` | 不要求保留未应用的细分控制笼 |
| **可变形角色与机构** | 进绑定动画的角色、服装、机械臂 | 关节均匀环线（肩肘腕胯膝踝）、五官口眼循环边、转动副枢轴精准对中、极限弯折或全行程零穿插 | 贴身内衬不可见遮挡面可按管线裁剪 |
| **实体 3D 打印**（`print`） | 切片打印与手办分件 | 100% 水密闭合流形（零开放边、零内翻面、零悬浮孤岛）、最小壁厚与公差止口达标 | G5（UV、PBR 贴图、双引擎渲染）标为不适用 |

## 二、五梯度评分细则（满分 100 分）

### G1 工程生死门（满分 15 分）
- **红线（任一不过即总评 `BLOCKED`）**：冷重开失败、非有限坐标、负缩放、数据贴图误标 `sRGB`、丢贴图或残留本机绝对路径、使用中空材质槽、切刀未关渲染可见、视口与渲染细分级差冲突。
- **计分点**：冷开与数据完整（5 分）+ 贴图打包/相对路径与色彩空间零差错（5 分）+ 渲染可见性与外部依赖闭包干净（5 分）。

### G2 拓扑四边面与大纲卫生（满分 25 分）
- **红线（L2 / L3 任一不过即 `BLOCKED`）**：米制非 `1.0`、静态件未应用缩放、缺少单一根集合、残留 `Cube.001` / `Material.004` 默认自动名、存在孤立点/退化面/共面闪烁/内翻面、曲面或变形区存在 N-gon 或 ≥6 边极点。
- **计分点**：大纲根集合、语义命名与清零孤立数据块（8 分）+ 物理尺寸、朝向 `-Y` 与合理枢轴（5 分）+ 四边面布线流向、极点落位与控制笼可编辑密度（12 分）。

### G3 大形比例与参考还原（满分 25 分）
- **计分点**：正侧背顶四向主剪影与体量比例（10 分）+ 一致性核对单标志性结构逐项命中率（10 分）+ 零件搭接、壁厚与负空间真实可信（5 分）。

### G4 光影法线与运动变形（满分 20 分）
- **计分点**：5.x 法线修改器栈顺序与锐边过渡（6 分）+ 条形斜光下主曲面反射平顺无波纹夹捏、接缝无黑线（8 分）+ 控制笼局部改型稳健 / 关节弯折或机构行程无穿插（6 分）。

### G5 UV 纹素、PBR 校准与双引擎品相（满分 15 分；白模/打印标 `applicable: false`）
- **计分点**：UV 接缝隐蔽、SubD 锁角、4–8 px 边距与棋盘格密度均衡（6 分）+ PBR 反照率物理区间 `30–240 sRGB` 与表面质感层次（5 分）+ Cycles、EEVEE Next 光追与干净工程纯贴图重建三方一致（4 分）。
